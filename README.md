# doottodooat

A Flutter example project. Also used as a starter for new projects.

## Run

Copy `.env.example` to `.env` and fill in your project's URL and publishable key (Supabase dashboard → Project Settings → API).

```
flutter run -d web-server --web-port 8080 --dart-define-from-file=.env
```

## Test

```
flutter test
```
